### Diwali_sales_Analysis
It is a data analysis project using python 
Technologies used: Python, numpy, pandas, matplotlib, seaborn

Key Highlightes of project:
-Performed Exploratory Data Analysis (EDA) on Diwali sales dataset to identify customer purchasing
pattern
-Cleaned and pre processed data by handling missing values, incorrect data types, and column removal
- Analysed sales trends based on gender, age group, marital status, state, and occupation.
-Created visualizations (bar charts, pie charts, scatter plots) to derive business insights.
-Identified high-revenue customer segments to support data-driven decision making
